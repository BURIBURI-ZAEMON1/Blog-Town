# Environment lighting asset

`studio.env` is the prefiltered Babylon.js sample environment, stored locally so
rendering does not depend on a third-party CDN at runtime.

Source: https://assets.babylonjs.com/environments/environmentSpecular.env
Repository: https://github.com/BabylonJS/Assets
License: see LICENSE-environment.txt.

All visible brick geometry, colours, minifigure face drawings and scene layout
are generated by this project's source. No LEGO logo or commercial model asset
is included. This is an independently authored interlocking-brick art style.
